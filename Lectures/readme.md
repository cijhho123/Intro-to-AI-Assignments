# Chapters
The Course "Intro to AI" as taught by Prof Eyal Shimoni in the CS department of BGU followed the subjects:
1. Introduction, Intelligent Agents, Environments
2. Search, Search Algorithms & Agents, Game Trees
3. Logical Agents, Predicate Calculus (FOPC), Inference in FOPC
4. Partial Order Planning, Contingent Planning
5. Decision Making Under Uncertainty, Bayes Networks Representation & Inference
6. Introduction to Learning, Learning Paradigms
